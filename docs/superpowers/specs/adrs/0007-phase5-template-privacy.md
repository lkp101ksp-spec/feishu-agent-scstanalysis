# ADR-007: 模板市场用户私有 vs 群聊共享

| 字段 | 值 |
|---|---|
| 状态 | 已批准（2026-08-09）|
| 决策者 | 用户 + Claude |
| 影响 Phase | Phase 5 |
| 相关 spec | §4 模板市场 |

---

## 背景

Phase 5 模板市场决定模板的可见范围。三种作用域：

1. **用户私有**：每个用户自己上传的模板仅自己可见可用
2. **群聊共享**：一个群聊内成员共享
3. **全员公共**：管理员审核后开放

---

## 选项

### A. 全员公共（Phase 1 类似）

类似插件市场，管理员审核后所有用户可见。

- **优点**：知识沉淀
- **缺点**：审核流复杂；MVP 风险高

### B. 群聊共享（折中）

一个群聊内成员共享模板。

- **优点**：群内复用效率高
- **缺点**：群聊级权限复杂；与"会话"概念冲突

### C. 用户私有（已选）

每个用户自己的模板仅自己可见可用。

- **优点**：实现简单（owner_open_id 校验）；MVP 风险低
- **缺点**：群内 / 全员复用需要再传一次

---

## 选择：**方案 C（用户私有）**

---

## 后果

### 正面

- 实现简单：每条记录 owner_open_id，列表/渲染/删除都校验
- 隐私风险低：用户模板不会被其他人意外看到
- MVP 风险最小

### 负面

- 群内 / 全员复用效率低（用户需上传到群）
- 知识沉淀缺失

### 中性

- 权限校验通过单元测试覆盖（3 tests）

---

## 回滚条件

1. 用户反馈"群内 / 全员复用"需求 ≥ 10% 用户
2. 用户主动把模板导出再上传 ≥ 100 次 / 天（说明共享缺失痛点）

回滚方案：Phase 6 引入 `scope` 字段（user / chat / public），与本 ADR 兼容（user 是默认）。
