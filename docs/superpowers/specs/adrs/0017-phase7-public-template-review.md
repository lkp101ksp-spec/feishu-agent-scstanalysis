# ADR-017: 公共模板审核流（admin + audit + reason）

| 字段 | 值 |
|---|---|
| 状态 | 已批准（2026-08-09）|
| 决策者 | 用户 + Claude |
| 影响 Phase | Phase 7 |
| 相关 spec | §5 公共模板 + 审核 |

---

## 背景

Phase 7 引入公共模板（全员可见）。需要审核流防止低质/恶意内容。

---

## 选项

### A. 强制审核流（已选 ✅）

私有 → submit → admin approve/reject → 公共。

- **优点**：风险可控；保留拒绝原因
- **缺点**：增加 admin 工作量

### B. 强制公共（无审核）

任何用户可创建公共模板。

- **优点**：流程最简
- **缺点**：高风险（恶意 / 低质内容）

### C. 仅审核不公开

私有可提交，但永远不通过。

- **优点**：流程最简
- **缺点**：无公共模板可见

---

## 选择：**方案 A（强制审核流）**

---

## 后果

### 正面

- 风险可控
- 拒绝原因写入 template_audit 表
- admin 校验（settings.admin_user_ids）

### 负面

- 增加 admin 工作量
- 用户提交后需等待审核

### 中性

- scope 字段扩展：'public_pending' / 'public' / 'user' / 'chat'

---

## 回滚条件

1. admin 审核工作量过大（≥ 50 提交/天）
2. 提交 → 审核延迟 > 7 天（≥ 50% 用户反馈）

回滚方案：自动审核（基于关键词 / 长度）+ 人工抽查。
