# ADR-012: 群聊共享 vs 公共模板

| 字段 | 值 |
|---|---|
| 状态 | 已批准（2026-08-09）|
| 决策者 | 用户 + Claude |
| 影响 Phase | Phase 6 |
| 相关 spec | §5 群聊共享 |

---

## 背景

Phase 5 模板市场仅支持私有（owner_open_id 校验）。Phase 6 需扩展可见性范围。三种作用域：

1. **私有（user）**：每个用户自己上传的仅自己可见
2. **群聊共享（chat）**：一个群聊内成员共享
3. **公共（public）**：管理员审核后全员可见

---

## 选项

### A. 仅私有（已选 ❌，继承 Phase 5）

每个用户私有。

- **优点**：实现最简
- **缺点**：群内复用效率低

### B. 私有 + 群聊共享（已选 ✅）

保留 Phase 5 私有；新增 chat_id 级共享。

- **优点**：覆盖大多数复用场景；权限边界清晰
- **缺点**：群聊成员校验需飞书 API（Phase 6 简化：仅 chat_id 匹配）

### C. 三级（私有 / 群聊 / 公共）

完整覆盖。

- **优点**：功能最全
- **缺点**：公共模板需管理员审核流；复杂度翻倍

---

## 选择：**方案 B（私有 + 群聊共享）**

---

## 后果

### 正面

- 覆盖大多数复用场景（80%）
- 权限边界清晰（user / chat 二分）
- 公共模板推到 Phase 7（不阻碍 Phase 6 交付）

### 负面

- 群聊成员校验需 Phase 7 加飞书 API
- 公共模板需求可能延迟满足

### 中性

- scope 字段设计为 enum；Phase 7 加 public 无需 schema 迁移

---

## 回滚条件

1. 用户反馈"群聊共享不够"（≥ 20% 要求 public）
2. 群聊成员校验漏洞被利用（≥ 1 起严重安全事件）

回滚方案：Phase 7 加 `scope='public'` + admin 审核流；与本 ADR 兼容。
