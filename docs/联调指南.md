# 飞书科研闭环 Agent 联调指南（Phase 10 T7，ADR-0030）

> 目标：从零配置到真飞书租户逐子系统冒烟。
> 前置：Windows 10+ / Python 3.12.10 / Docker Desktop（pg 层可选）。
> 工程环境：`.venv`（ADR-0028），依赖见 `requirements-lock.txt`。

---

## 1. 环境搭建（一次性）

```powershell
python -m venv .venv                                  # 必须是 3.12.10（ADR-0028 钉死）
.venv\Scripts\pip install -e ".[dev]" -i https://pypi.tuna.tsinghua.edu.cn/simple
# 复核锁文件一致性（可选）：pip freeze 对比 requirements-lock.txt
```

| # | 事项 | 位置 | 备注 |

| 1 | 创建企业自建应用 | 开放平台 > 应用 | 记录 App ID / App Secret |

## 3. 内网穿透三方案（接收飞书 webhook 回调）

| 方案 | 适用 | 做法 | 权衡 |
|------|------|------|------|
| A. 长连接（WebSocket） | 官方推荐、无需公网 | SDK 长连接模式订阅事件，`FEISHU_WEBHOOK_SECRET` 仍需配 | 需代码侧用 open-platform 长连接客户端；当前 gateway 走 webhook，选此方案需改造 |
| B. 内网穿透工具 | 本机开发最快 | ngrok / cpolar / 花生壳：`ngrok http 8000`，把分配的 https 域名填到事件订阅 URL | 第三方域名有稳定性/合规问题；本地开发首选 |
| C. 云服务器反代 | 有公网机器 | frp/caddy 反代到本机 8000，事件 URL 填公网域名 | 最稳定；需要一台 VPS |

> 当前 gateway 为 FastAPI webhook（`/webhook`），**方案 B 是本仓库现状下最快路径**。

## 4. 启动序列

```powershell
copy .env.example .env          # 逐项填写（§2 checklist 产物 + LLM + DB）
python scripts/config_check.py --env-file .env --probe --docker
#   → exit 0（errors 为空）才继续；warnings 按场景判断是否可忽略

docker compose up -d postgres   # 本地 PG（端口 5433 避让本机 5432）
# 生产库另建；DATABASE_URL 指向目标库

.venv\Scripts\alembic upgrade head        # 建表（0001+0002 共 17 表 + GIN）
.venv\Scripts\python -m uvicorn gateway.app:app --port 8000
```

## 5. 逐子系统冒烟清单

按依赖顺序执行；任一步失败先看服务日志再回查对应 checklist 项。

| # | 子系统 | 操作 | 预期 | 失败排查 |
|---|--------|------|------|----------|
| 1 | Webhook 验签 | 飞书发 challenge 事件（或 curl 重放） | 日志出现验签通过、返回 challenge | `FEISHU_WEBHOOK_SECRET` 与平台不一致 |
| 2 | IM 收消息 | 群里 @机器人 `help` | 机器人回指令菜单 | 事件订阅未发布/未拉群；权限 im:message |

| 4 | 云文档写入 | 触发一次会触发写文档的流程 | 目标 doc 出现新内容块 | docx:document 权限；文档需机器人可编辑 |

| 6 | 评论闭环 | 在绑定文档块下发评论 `/revise <tid> 描述` | 版本升级 + diff 卡片推送 | 评论权限（Phase 7/8 ADR-0015/0020） |

## 6. 常见排障

- **双解释器漂移**（ModuleNotFoundError 但 pip 装过）：确认命令走 `.venv\Scripts\`（Phase 8 踩坑，ADR-0028 由来）。
- **`No module named 'psycopg2'`**：`postgresql://` 前缀会找 psycopg2；改 `postgresql+psycopg://`（psycopg3）。
- **alembic UnicodeDecodeError（GBK）**：Windows 下不要用 `Config("alembic.ini")` 传中文注释 ini；参考 `tests/pg/test_pg_migrations.py` 的程序化 cfg。
- **pg 层 6 deselected**：`-m pg` 标记必须在测试模块内声明 `pytestmark`（conftest 不传播）。
- **回调收不到**：先过 §3 穿透，再查应用是否已发布版本、机器人是否在群内。
